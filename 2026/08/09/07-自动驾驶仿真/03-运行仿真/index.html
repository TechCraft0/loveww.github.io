03 运行仿真

3.1 启动 CARLA 服务端

首次启动编译着色器较慢，地图可能先黑着，等编完就正常。编辑器打开后：

  1. 确认加载了 CARLA 地图（视口能看到城镇；空的话在 Content Browser 里 CarlaUE4/Maps/ 双击 Town10HD_Opt 等）。
  2. 点顶部 ▶ Play 进入仿真运行模式。

仿真服务端监听端口 2000（RPC）/ 2001（流）。

3.2 生成 NPC 交通（模拟真实场景）

参数：

  • -n 车辆数（默认 30，真实交通建议 80~100）
  • -w 行人数（默认 10，建议 30~50）

⚠️ generate_traffic.py 用 conda 的 carla 环境（要 import carla）。数量太多会降仿真 FPS，按机器性能调。

3.3 Python 客户端测试

再开一个终端测试客户端连接：

若脚本能跑、画面出现车/人，说明 0.9.16 客户端 ↔ 服务端连接正常。

3.4 停止

  • 编辑器里再按 Play / Esc 停止仿真。
  • 关闭编辑器窗口即停止服务端。

3.5 性能小提示

  • FPS 低：编辑器 Edit -> Editor Preferences -> Performance，关掉 Use less CPU when in background。
  • 首次慢：着色器编译，后续有缓存（DerivedDataCache）会快。
  • 日常纯跑仿真（没改 C++ 代码）直接跑 editor 二进制最快（见 02 章 2.5）。
