02 构建 UE4 与 CARLA

CARLA 0.9.16 基于 UE4.26（CARLA 的 fork）。先编 UE4，再编 CARLA。整个过程较长（数小时），且本教程环境踩了 4 个坑，都配有修复。

2.1 构建 Unreal Engine 4.26

CARLA 用的是 UE4.26 的专用 fork（含 CARLA 补丁）。需要 GitHub 账号关联 Epic Games 组织。

⚠️ 不要用 make -j$(nproc)，会失败。Clang 会自动用满核心。

验证：cd Engine/Binaries/Linux && ./UE4Editor 能打开编辑器即可。
