CARLA + ROS2 + rf-DETR + OC-SORT 感知仿真教程

本教程记录从零搭建 CARLA 0.9.16 仿真环境、接入 ROS2 话题、用 rf-DETR (TensorRT) 做目标检测、再用 OC-SORT 做多目标跟踪并绘制移动轨迹的完整过程。最终在 rviz2 中看到带 ID 和轨迹的检测结果。

路径约定（请按你的实际路径替换）

本教程用以下占位符，实际操作时替换成你的路径：

占位符 含义（示例）
~/carla_project/carla CARLA 0.9.16 源码
~/carla_project/UnrealEngine_4.26 UE4.26 引擎
~/carla_project/ros2_ws ROS2 工作空间
~/models/rf-detr rf-DETR 模型仓库
~/models/OC_SORT OC-SORT 跟踪仓库
conda 环境 carla CARLA Python 客户端环境

适用环境

  • Ubuntu 22.04
  • NVIDIA GPU（本教程用 CUDA 12.8 / 驱动 570+）
  • TensorRT 10.9
  • ROS2 Humble
  • CARLA 0.9.16 + UE4.26

教程中标注 ⚠️ 的是实际踩坑点，配有解决方案，值得注意。
